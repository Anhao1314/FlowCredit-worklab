# The Creation of Adam

Michelangelo, circa 1511. Public-domain artwork and faithful reproduction (PD-Art).
Source: https://commons.wikimedia.org/wiki/File:The_Creation_of_Adam.jpg

`creation-of-adam.jpg` is the existing 1,614 × 741 local reproduction used by the
Creation concept. Only the fingertip region is rendered; cropping and edge-material
conversion happen in Canvas. The asset is served locally with no CDN requests.
Artwork is not covered by the repository's code license. No private reference video,
screenshots, embedded mock workspace or historical runtime data are included.
